# DontKillMyApp

Universal background-killer pacifier for HyperOS, OneUI, XOS/HiOS, ColorOS & AOSP 8–16. OEM-aware, with interactive WebUI.

## Install

Flash via KernelSU / APatch / Magisk, then open the WebUI (MMRL) to configure per-app rules.

## What it does

Keeps your apps alive: disables aggressive OEM battery killers per-app instead of one global toggle.
